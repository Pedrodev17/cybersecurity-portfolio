### 📋 Sobre

Repositório com exercícios práticos de cybersecurity, feitos como parte da minha transição para **Security Analyst / SOC Analyst**. Cada exercício simula um cenário real e aplica conceitos de frameworks reconhecidos do mercado (NIST, CVSS, IAM, LGPD/GDPR).
